# YouTube Caption & Whisper AI Transcript Extractor: free n8n workflow

A free n8n workflow that runs the [YouTube Caption & Whisper AI Transcript Extractor](https://apify.com/nimbryxo-studio/youtube-caption-and-whisper-ai-transcript) Apify Actor and returns `video_id`, `title`, `channel_name`, `publishedAt`, `transcript_language` and more as clean, deduped rows for Google Sheets or your next node.

- Job: YouTube caption scraper
- Platform: YouTube
- Workflow file: [workflows/youtube-caption-and-whisper-ai-transcript-extractor.json](../workflows/youtube-caption-and-whisper-ai-transcript-extractor.json) (raw: `https://raw.githubusercontent.com/bolvein-firex/scraping-n8n-workflows/main/workflows/youtube-caption-and-whisper-ai-transcript-extractor.json`)

- Agent skill for the same Actor: https://github.com/bolvein-firex/scraping-skills/blob/main/skills/youtube-caption-and-whisper-ai-transcript-extractor/SKILL.md

## What it does

Get timestamped transcripts from YouTube videos in your preferred language, with optional AI transcription for videos that have no captions at all. Returns full text, timed segments, and core video metadata.

## Inputs

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `mode` | string | no | videos | What to scrape: specific videos, a channel's uploads, or a playlist. |
| `videoUrls` | array | no |  | YouTube watch URLs, youtu.be short links, Shorts/embed URLs, or plain 11-character video IDs (mode=videos). Duplicate IDs are processed once. |
| `channelUrls` | array | no |  | Channel URLs or handles (mode=channel), e.g. `https://www.youtube.com/@TED,` `https://www.youtube.com/channel/UC...,` or @TED. |
| `maxVideosPerChannel` | integer | no | 50 | Maximum number of videos to enumerate from each channel (mode=channel). 1-1,000. |
| `playlistUrls` | array | no |  | Playlist URLs or IDs (mode=playlist), e.g. `https://www.youtube.com/playlist?list=PL...` or PL.... Every video in the playlist is transcribed. |
| `maxVideosPerPlaylist` | integer | no | 50 | Maximum number of videos to enumerate from each playlist (mode=playlist). 1-1,000. |
| `language` | string | no |  | Caption language to fetch. Leave Auto-detect to use the video's original language. |
| `includeAutoGenerated` | boolean | no | true | Whether to include auto-generated captions when manual captions are not available. |
| `useWhisper` | boolean | no | true | When YouTube has no transcript (disabled captions, music-only, or blocked), download the audio and transcribe with Whisper AI (faster-whisper, CPU). Adds ~30-180 s per video. |
| `whisperModel` | string | no | base | Whisper model size to use when `useWhisper` is enabled. Larger = more accurate but slower and more RAM. 'base' is balanced. |
| `includeWordTimings` | boolean | no | false | Add a wordTimings array with word-level start/end times. Only auto-generated YouTube captions expose word timings; manual captions and AI transcripts do not. |
| `maxWhisperMinutes` | integer | no |  | Leave unset for the legacy behavior (AI enabled with no length limit). Set to 0 explicitly to disable AI transcription. |

2 more optional fields on the Actor's Input tab.

Starter input (edit it in **Configure input**):

```json
{
  "videoUrls": [
    "https://www.youtube.com/watch?v=jNQXAC9IVRw"
  ],
  "whisperModel": "tiny",
  "proxyCountry": "GB"
}
```

The input passes the Actor's input schema (checked at every publish). First run: `maxVideosPerChannel` = 50, small enough for the 300-second sync wait; raise it once the rows look right.

## Nodes

Daily trigger → Configure input → Run Apify Actor → Normalize + dedupe → Rows ready → Google Sheets (optional, disabled)

**Normalize + dedupe** drops identical rows (this output has no stable row ID).

## Import

1. In n8n: **⋯ → Import from URL** and paste `https://raw.githubusercontent.com/bolvein-firex/scraping-n8n-workflows/main/workflows/youtube-caption-and-whisper-ai-transcript-extractor.json`.
2. Create a **Query Auth** credential (name `token`, value your Apify API token) and select it in **Run Apify Actor**.
3. Edit **Configure input**, then **Execute workflow**.
