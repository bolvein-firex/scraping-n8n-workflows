# Import a workflow

1. Download a JSON file from `workflows/`.
2. In n8n, open **Workflows** -> **Import from file**.
3. Select the file.
4. Open **Run Scraper Finder actor** and select the `Apify API Token` credential.
5. Edit **Configure input**.
6. Click **Execute workflow**.

The Google Sheets node is disabled by default. Enable it after adding a Google Sheets credential and sheet ID.
